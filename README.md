# Dispath

## Team Collaboration

This project was developed as a collaborative group project focused on distributed systems architecture, backend services, and logistics workflow optimization.

Team Members:
- Olawale Tijani
- Arpandeep Kaur
- Roya Mohammandi
- Matthew Lu

Dispath is a microservices-based logistics and delivery management platform designed to optimize delivery coordination, driver tracking, and customer order management in real time.

## Features

- Real-time delivery tracking
- Route optimization system
- Driver management dashboard
- Customer and order management
- API Gateway architecture
- Service Registry for microservice discovery
- Interactive delivery monitoring dashboard

## Tech Stack

- Java
- Spring Boot
- React
- MongoDB
- SQL
- Google Maps API
- REST APIs

## Microservices

- authAndAPI-gateway
- customerAndOrder-service
- driverAndTracking-service
- routing-service
- service-registry

## Purpose

This project was developed to explore scalable backend architecture, distributed systems, and modern logistics workflows using microservices and real-time data handling.
